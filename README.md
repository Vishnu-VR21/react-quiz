🧠 React Quiz App

This is a simple quiz application built using React. Users can answer multiple-choice questions and see their score at the end.

🚀 Features
Multiple-choice questions
Shows score after completing the quiz
Restart quiz option
Simple and clean user interface
🛠️ Technologies Used
React
JavaScript
CSS
📂 Project Structure
src/
  components/
  data/
  App.jsx
  main.jsx
⚙️ How to Run
Clone the project:
git clone https://github.com/your-username/react-quiz-app.git
Go to the folder:
cd react-quiz-app
Install dependencies:
npm install
Start the app:
npm run dev
🧩 How It Works
The app shows one question at a time
User selects an answer
At the end, the total score is displayed
